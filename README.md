# RestBooking Mobile

Мобильное приложение (React Native / Expo) для платформы RestBooking — полностью
повторяет функционал **и дизайн** веб-версии для всех 4 ролей: Клиент, Админ
заведения, Админ сети (агрегатор), Системный администратор.

## Дизайн

Палитра взята напрямую из `tailwind.config.js` и `index.css` сайта — светлая тема,
белые карточки с тенью, три акцентных цвета:
- **brand / оранжевый** (`#EA580C`) — основной цвет, кнопки, бренд
- **chaikhana / бирюза** (`#17A08F`) — акцент, вдохновлён рыштанской майоликой
- **saffron / золотой** (`#F59E0B`) — рейтинги и бейджи, как плов-акцент на сайте

Карточки заведений в каталоге повторяют сайт: полноширинное фото (или градиент по
типу заведения, если фото нет), бейдж типа заведения и золотой рейтинг-бейдж поверх.

## Экраны

**Клиент** — каталог с фильтрами, страница заведения с бронированием (выбор стола →
даты → времени), избранное, мои брони + отзывы, ИИ-ассистент, статьи, профиль.

**Админ заведения** — обзор/статистика, управление бронями (подтвердить/отклонить/
завершить/неявка/ручная бронь), залы и столы, клиенты, отзывы с ответами, настройки
заведения (часы работы, правила брони, фото), стоп-лист дат, Telegram-бот, чат с
поддержкой платформы.

**Админ сети** — статистика по сети, заведения сети (создание, активация), админы
заведений, чат с поддержкой.

**Системный администратор** — обзор платформы, все заведения (модерация, активация,
привязка к сети/тарифу), сети, отзывы платформы, города/районы, баннеры, тарифы,
статьи + категории, чаты со всеми обращениями.

## Запуск

1. Установи зависимости:
   ```
   npm install
   ```

2. Укажи адрес своего backend (тот же сервер, где крутится `/api` через Caddy —
   смотри `restbooking-app-deploy.zip`). Скопируй `.env.example` в `.env`:
   ```
   cp .env.example .env
   ```
   и пропиши реальный домен:
   ```
   EXPO_PUBLIC_API_BASE_URL=https://твой-домен.uz/api
   ```
   Для локальной разработки с backend на компе — используй адрес компа в локальной
   сети (не `localhost`, так как телефон/эмулятор не видит `localhost` компа):
   `http://192.168.х.х:8080/api`.

3. Запусти:
   ```
   npx expo start
   ```
   Отсканируй QR-код приложением **Expo Go** на телефоне, либо запусти на
   эмуляторе (`npx expo start --android` / `--ios`).

## Сборка APK/IPA

Для реальной сборки под установку на телефон без Expo Go нужен EAS Build:
```
npm install -g eas-cli
eas login
eas build:configure
eas build --platform android --profile preview
```
Подробнее: https://docs.expo.dev/build/introduction/

## Структура

```
app/
  (auth)/          вход, регистрация
  (client)/        клиентская часть (таб-навигация)
  (venue-admin)/   админка заведения (таб-навигация)
  (aggregator)/    админка сети (таб-навигация)
  (system-admin)/  системный админ (таб-навигация)
lib/
  api.ts           весь API-клиент (JWT, refresh, все эндпоинты)
  auth-context.tsx контекст авторизации
  types.ts         типы данных
  theme.ts         цвета/отступы
components/        переиспользуемые UI-компоненты
```

Все скрины используют реальные эндпоинты твоего Spring Boot backend — переносить
данные или менять backend не нужно, только указать правильный `EXPO_PUBLIC_API_BASE_URL`.
